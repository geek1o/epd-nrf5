# Кандидаты прошивок

[Скачать архив приложений](epd-russian-calendar-candidates.zip) · [Контрольные суммы и размеры](manifest.json)

Архив содержит отдельные каталоги `nrf51-ru` и `nrf52-ru`: application HEX/BIN, ELF/MAP, JSON, application-only OTA ZIP. Это сборки поддерживаемых исходных конфигураций, **без проверки на конкретном Hema пользователя**. Коммит исходников указан в manifest и JSON; последующий коммит сохраняет результаты сборки.

HEX не содержит загрузчика/SoftDevice/UICR. BIN не адресован; адреса в manifest. OTA подпись/хеш проверены, но совместимость ключа установленного загрузчика не подтверждена. Не устанавливайте пакет только по названию ценника или факту наличия BLE. [Выбор, backup и восстановление](../docs/flashing_ru.md).

Версия приложения `0x1c`. Размеры актуальных образов указаны в manifest.json. Превью календаря и часов включены в архив. Проверка загрузки: начальный SP и Reset_Handler находятся в допустимых диапазонах, HEX не содержит областей загрузчика/SoftDevice/UICR, OTA BIN совпадает с собранным BIN.
